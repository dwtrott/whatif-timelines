How this works

  1. Retrieve. For your topic, the server pulls Wikipedia revisions as they existed on the cutoff date (so agents can't peek at the ending), GDELT news headlines up to the cutoff, present-day article text (only for the actual-history baseline) and any seed documents you paste.
  2. Ground. A leakage-filter pass rewrites the material into a briefing containing only what was knowable at the cutoff, and lists what it stripped.
  3. Cast. The model designs the actors whose decisions drive the situation — they become the agent swarm.
  4. Baseline. Actual events between the anchor and today are extracted onto the grey lane. If the horizon is in the future, a baseline forecast branch starts from today.
  5. Fork. Click an event → What if… → a new branch. Every period, all agents decide concurrently (with only cutoff-safe knowledge plus the branch's own history), and an arbiter "world model" adjudicates what happens, scores divergence from the parent lane, and updates each agent's memory.
  6. Analyse. Each finished branch gets a report (mechanism, probability, signposts, convergence). Interview any agent inside any branch, or compare two branches.

Caveat: for topics older than ~2002 Wikipedia has no pre-event revision, so the leakage filter is doing the work — check the "stripped" notes in the branch briefing. All forecasts are model output, not evidence.
